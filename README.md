# DmFirst Landing Page & Admin Panel

A modern, responsive dark-themed landing page with live countdown timer, auto-redirect, Meta Pixel tracking, and a password-protected admin control panel with Firebase Cloud Sync.

---

## 📁 Repository Structure

```text
├── index.html        # Main Landing Page (Public View + Meta Pixel)
├── admin.html        # Password Protected Admin Control Panel
├── styles.css        # Stylesheet (Fully Relative & Portable)
├── script.js        # Landing Page Script (Firebase Cloud Sync + Timer)
├── admin.js         # Admin Panel Script (Password Gate + Image Optimizer)
└── assets/
    └── logo.jpg      # DmFirst 3D Gold Logo Graphic
```

---

## 🚀 How to Deploy on GitHub Pages

1. Create a new GitHub Repository (or use an existing one, e.g. `webproject25274/dmfirst`).
2. Upload all files from this folder directly to the **root** of your repository.
3. Go to **Settings ➔ Pages** in your GitHub repository.
4. Set **Source** to `Deploy from a branch` and select **`main`** / **`/ (root)`**.
5. Click **Save**.

Your website will be published live at:
🌐 **`https://<your-username>.github.io/<repo-name>/`**
